# .github — padrões da organização

Repositório dos arquivos de comunidade padrão do Brasil Data Hub. É público por
exigência do GitHub: defaults de organização só são herdados a partir de um
repositório `.github` público.

Este arquivo é um **índice**. Ele não contém regra — leia os documentos abaixo,
que são a fonte de verdade
([`AGENT-ENTRYPOINTS.md`](https://github.com/BrasilDataHub/docs/blob/main/standards/AGENT-ENTRYPOINTS.md)).

## Ao alterar um formulário

Um formulário existe por causa de um Issue Type, e os dois precisam continuar
dizendo a mesma coisa. Mexeu em campo, obrigatoriedade ou tipo aqui? Confira
`WORK-MANAGEMENT.md` no mesmo trabalho.

**Este repositório é público.** Nada de nome de cliente, host interno,
credencial ou detalhe operacional nos formulários.
